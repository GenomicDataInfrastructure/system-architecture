# Sources

Every document the architecture cites. Cite an entry in a page with `<Cite id="…" />`. To add a source, edit `src/data/sources.json`.

Status values: **adopted** (legal act in force), **published** (final deliverable or standard), **draft** (not final, cite with care), **candidate** (found but not yet checked by the taskforce).
