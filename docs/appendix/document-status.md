# Document status

Who owns and reviews each page, its status and when it was last reviewed. Generated from the front matter of each page.

| Status | Meaning |
|---|---|
| Placeholder | Structure only; no content yet. |
| Draft | Content being written by the owner. |
| In review | Content complete; waiting for the reviewers' approval in a pull request. |
| Approved | Reviewed and approved. `last_reviewed` gives the date. |

The full history of every page (who changed what, and when) is in the Git history on GitHub. Each page also shows the date and author of its last change at the bottom.
