This decision is taken in wave 3, before the level-1 building blocks are drawn, because it shapes them (decision D-027). The full concept is described in [8.3 Security and risk management](/concepts/security) (wave 5), which builds on this decision.

## What this page must answer

- Which trust boundaries the system has: between the European part, each country's national part, the 1+MG IT infrastructure providers and the User Organisations.
- What each crossing requires: authentication of the systems and persons involved, encryption, and logging.
- Which security baseline each operator meets, and how it is audited or certified.
- The options considered, and what each one means for the building blocks of chapter 5 and the deployment of chapter 7.
