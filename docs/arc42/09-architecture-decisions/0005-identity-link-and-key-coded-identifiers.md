This decision is taken in wave 3, before the level-1 building blocks are drawn, because it shapes them (decision D-027). The full concept is described in [8.7 Key-coded identifiers and data linkage](/concepts/identifiers-and-linkage) (wave 5), which builds on this decision.

## What this page must answer

- Which interfaces connect the data subject services to the national service that holds the link between a data subject's identity and their key-coded identifiers. Where the link is held is a national choice (wave 1); the interfaces are not.
- Who generates key-coded identifiers, and whether data are linked only within a country or also across countries.
- What the Genome EDIC CC's identification management service offers to countries that use it.
- The options considered, and what each one means for the building blocks of chapter 5.
